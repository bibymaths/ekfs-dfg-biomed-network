# Legacy Analysis: Nobel Prize Cohort

This directory preserves the historical `noblePrize.Rmd` proof-of-concept from `Juselius_secretdoor`.
It established that the OpenAlex author resolution, publication retrieval, and coauthorship graph pipeline was not intrinsically tied to the Jusélius foundation, but could operate on alternative researcher cohorts.

In the redesigned EKFS-DFG platform, this concept is formalized into an extensible multi-cohort architecture capable of ingesting EKFS project grantees, DFG GEPRIS investigators, or arbitrary external cohorts.
